# Автотесты для Stellar Burgers

Проект автоматизированного тестирования сайта Stellar Burgers.

## Описание

Автотесты для проверки функциональности сайта https://stellarburgers.education-services.ru

## Структура проекта

```
Sprint_5/
├── pages/                    # Page Object классы
│   ├── base_page.py          # Базовый класс страницы
│   ├── main_page.py          # Главная страница
│   ├── login_page.py         # Страница входа
│   ├── registration_page.py  # Страница регистрации
│   ├── forgot_password_page.py # Страница восстановления пароля
│   └── personal_account_page.py # Личный кабинет
├── tests/                    # Тестовые файлы
│   ├── test_registration.py  # Тесты регистрации
│   ├── test_main_page.py     # Тесты главной страницы
│   ├── test_personal_account_page.py # Тесты личного кабинета
│   ├── test_login_via_registration_page.py # Тесты входа через страницу регистрации
│   ├── test_login_via_forgot_password_page.py # Тесты входа через страницу восстановления пароля
│   └── curl.py               # URL-адреса для тестов
├── conftest.py               # Фикстуры pytest
└── locators.py               # Локаторы элементов
```

### Регистрация
- Успешная регистрация пользователя
- Ошибка при вводе некорректного пароля (менее 6 символов)

### Вход в систему
- Вход через кнопку "Войти в аккаунт" на главной странице
- Вход через кнопку "Личный Кабинет"
- Вход через кнопку "Войти" на странице регистрации
- Вход через кнопку "Войти" на странице восстановления пароля

### Личный кабинет
- Переход в конструктор из личного кабинета
- Переход на главную страницу по клику на логотип
- Выход из аккаунта

### Конструктор
- Переключение между вкладками "Булки", "Соусы", "Начинки"
